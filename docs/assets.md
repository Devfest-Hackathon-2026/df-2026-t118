# 外部素材の台帳

著作物利用シート（提出物）を書くための元データ。**素材を使った時点でここに追記する**。提出前にまとめて思い出すのは不可能で、記載漏れはルール違反になる。

対象は、自分たちで作っていないものすべて。

- 画像・イラスト・アイコン・ロゴ
- フォント
- 音源・効果音・BGM（デモ動画に使うものを含む）
- 動画素材
- デモ・シードデータに使った外部コンテンツ（記事・動画の URL、サムネイル）
- OSS ライブラリ（提出シートの対象かは配布フォーマットの指示に従う。判断がつかないものは記載しておく）
- 生成 AI で作った素材（生成に使ったツールとプロンプトの要旨を備考に書く）

### 記入のしかた

- **ライセンス**: 名称を正確に（`CC BY 4.0`、`Apache-2.0`、`Google Fonts の Open Font License` など）。「フリー素材」は不可
- **利用箇所**: `ホーム画面の背景` `デモ動画 0:12-0:20 の BGM` のように特定できる粒度で
- **改変**: トリミング・色調補正・再エンコードも改変にあたる
- **クレジット表記**: 必要な場合、どこに表記したかも書く

## 使わないもの

判断に迷うくらいなら使わない。

- ライセンスが明示されていない素材
- 商用利用・二次配布の可否が確認できない素材
- 第三者が写っている写真・映像（デモ画面のスクリーンショットを含む）
- 実在する企業・サービスのロゴ（デモ対象として必要な場合を除く）
- 他社 AI ツールの名称・ロゴ（審査対象外の条件に該当する）
