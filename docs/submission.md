## 審査対象外になる条件と対応

| 条件 | このプロジェクトでの対応 |
|---|---|
| Google Cloud 実行基盤を使っていない | App Engine / Compute Engine / GKE / Cloud Run / Firebase App Hosting / Firebase Hosting のうち 1 つ以上でアプリを動かす。使ったものを説明ドキュメント 3.1 でチェックする |
| 必須項目の不足 | 説明ドキュメントの 1〜5 と提出物 1〜4 を揃える。チェックリストで最終確認する |
| デモ動画の偽装 | 実際に動いている画面を録る。未実装の機能を実装済みに見せない。編集で処理時間を詰める場合はその旨を示す |
| 他社 AI ツールが前面に出ている | プロダクトが使う AI は Gemini に統一する。画面・動画・ドキュメント・スライドに他社 AI の名前やロゴを出さない |
| テーマやカテゴリから外れている | カテゴリは**クリエイティブ**。選択肢は 医療・福祉 / 観光 / 教育 / エンターテインメント / クリエイティブ の 5 つで、カテゴリ外は審査対象外。要件・デモシナリオ・説明ドキュメント・動画の訴求をすべてクリエイティブに接地させる |
| 不適切な内容 | デモに使う URL・画像・サンプルデータに第三者の個人情報や不適切な内容を含めない |
| ルール違反 | 締切・形式・公開設定を守る |
