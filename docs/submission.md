## 審査対象外になる条件と対応

| 条件 | このプロジェクトでの対応 |
|---|---|
| Google Cloud 実行基盤を使っていない | Firebase Hosting でアプリを動かす。説明ドキュメント 3.1 でチェックする |
| 必須項目の不足 | 説明ドキュメントの 1〜5 と提出物 1〜5 を揃える。チェックリストで最終確認する |
| デモ動画の偽装 | 実際に動いている画面を録る。未実装の機能を実装済みに見せない。編集で処理時間を詰める場合はその旨を示す |
| 他社 AI ツールが前面に出ている | プロダクトが使う AI は Gemini に統一する。画面・動画・スライドに他社 AI の名前やロゴを出さない |
| テーマやカテゴリから外れている | カテゴリは**クリエイティブ**。要件・デモシナリオ・説明ドキュメント・動画の訴求をすべてクリエイティブに接地させる |
| 不適切な内容 | デモに使う URL・画像・サンプルデータに第三者の個人情報や不適切な内容を含めない |
| ルール違反 | 締切・形式・公開設定・ファイル名の規則を守る |

## デプロイ URL と実行環境の凍結

アプリは Web アプリなので、説明ドキュメント「5. プロジェクトをデプロイした URL」に公開先の URL を書く（記入済み: https://hannari-hustlers.web.app ）。

**提出締切から 2026-11-14（土）終了まで、実行環境を凍結する。**

- 禁止: 再デプロイ、バグ修正、プロンプト変更、モデル変更、検索用データの追加、機能に関わる設定変更
- 認められる: 審査操作によるデータ更新、自動スケール、通常の定期処理、クレジット補充
- クレジット補充以外の手動復旧（再起動・認証更新など）は認められない。審査時に停止していても、提出資料と動画で採点される
- 予算上限・クレジット切れで落ちないことを 11/10 と 11/13 に確認する
